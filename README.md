## Projects

### 1. B2B Marketing Mix Modeling with Google Meridian
**File:** Meridian_implementation_V2.ipynb

Built a Bayesian MMM on a simulated B2B enterprise dataset 
(156 weeks, 8 channels, $17M+ weekly pipeline KPI) using 
Google Meridian to quantify media ROI and identify budget 
optimization opportunities.

**Key findings:**
- Baseline drives 70% of pipeline — media contributes 30%
- Branded search highest ROI at $2.48 per dollar spent
- CTV and display over-invested relative to returns
- V1 model had 97.3 health score but ROIs were 2-4x inflated
- V2 corrected configuration recovered true baseline (76%)

**Tech stack:** Python, Google Meridian, TensorFlow Probability, 
xarray, arviz
